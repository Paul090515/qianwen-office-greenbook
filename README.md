## 离线阅读与编辑

打开 `index.html` 或 `千问办公绿皮书.html` 可离线阅读，两个网页内容一致且内嵌页面图片。需要改文稿时，编辑 `千问办公绿皮书.md`，并把 `assets/` 文件夹一起保留，因为 Markdown 图片引用依赖这些配图。要单独交给编辑者，可使用 `千问办公绿皮书_可编辑稿与配图.zip`：其中有 Markdown、实际引用的配图、练习文件和来源说明，不含网页文件。

## 练习材料

`practice/` 里有活动报名和工具借还两组模拟 CSV 及核对答案 JSON。日期、人物和记录均用于练习，不是真实社区/业务数据。工具借还表固定按 2026-11-01 当日结束时核对；分类规则见使用说明和答案文件。请先看表头与口径，再核对结果。

产品入口、界面和权限会随账号与版本变化。官方示例图片不是读者账号的实测截图；使用前请查当前官方说明和组织规则。
