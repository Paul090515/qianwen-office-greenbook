## 19 走完一个共享工具角小项目

前面的章节分别练过读材料、写说明、算表格和交接。本篇把这些动作接成一个完整项目：为社区共享工具角整理一次借还台账，做出状态汇总和下一班能继续使用的说明。材料、统计规则、核对答案都放在书里，你可以独立完成，不需要真实住户信息。

![共享工具角的十件工具怎样核对](assets/tool-project-v2.svg)

### 项目目标与边界先写清楚

你的角色是临时整理资料的人。本次只处理十件模拟工具的台账，核对时点固定为**2026年11月1日结束时**。这个时点是练习条件，不跟着电脑当天日期变化。

希望交付三份成果：一张包含原始记录与状态汇总的表、一段给值班人员看的简明情况说明、一份交接检查清单。先生成草稿和文件副本，不修改唯一原表，不联系借用人，也不发布真实借还信息。

在开卷的练习下载区领取「工具借还练习.csv」和「工具借还核对答案.json」。前者可用Excel或WPS打开；后者是纯文字答案文件，用文本编辑器即可查看。本篇也直接列出关键答案，不把会打开JSON当作学习门槛。

### 材料里有什么，没有什么

每一行代表一件工具，共五列：工具编号、工具名称、借出日期、约定归还日、实际归还日。工具编号从T001到T010，不包含姓名、手机号、家庭住址和费用。空白格具有本题约定的含义，不能一律当作数据丢失。

T003和T007从未借出，三个日期格都为空；T005和T008已有实际归还日期；其他六件已借出且实际归还日为空。本题约定前四件属于在架，后六件属于借出。这种规则只适用于这份练习；真实台账若还有维修、报废或遗失状态，要先补充规则再计算。

“在架”只说明记录中的借还状态，不表示已经检查工具性能。材料没有损坏情况、责任归属或联系人，成果里也不能据此安排处罚、认定责任或声称每件工具都能正常使用。

### 第一步，确认文件读取和统计规则

先让千问办公报告字段与行数，再复述规则。这里特意安排了“今日到期”：T002约定11月1日归还，在指定时点的本题分类中归入今日到期，不与已经逾期混在一起。若按当前系统日期计算，结果可能完全不同。

```text
请读取附件“工具借还练习.csv”，这是本书原创模拟材料。
先报告字段、数据行数、工具编号是否唯一，以及哪些日期格为空。
核对时点固定为2026年11月1日结束时，不使用系统今天的日期。
分类规则：
1. 从未借出，或已经填写实际归还日的工具，归为“在架”。
2. 已借出但实际归还日为空，归为“借出”。
3. 在“借出”内部，约定归还日早于2026-11-01为“逾期”；等于为“今日到期”；晚于为“未到期”。
若出现无法按规则处理的记录，请单独列出，不擅自补日期。
本轮只复述读取结果和规则，不制作图表，不改原文件。
```

通过条件是十行、十个不同编号、五个字段，且正确区分“从未借出”的空白和“尚未归还”的空白。若AI把所有空白都补成今天，必须退回这一轮修正，不能沿用错误结果继续做图。

### 第二步，逐件分类后再汇总

确认读取正确后，让它列出每件工具的分类和依据。你可以按下面的答案逐行检查：

| 编号 | 工具 | 本题分类 |
| --- | --- | --- |
| T001 | 羊角锤 | 借出中的逾期 |
| T002 | 橡胶锤 | 借出中的今日到期 |
| T003 | 小木锤 | 在架 |
| T004 | 三米卷尺 | 借出中的未到期 |
| T005 | 五米卷尺 | 在架，已归还 |
| T006 | 长柄手电 | 借出中的未到期 |
| T007 | 迷你手电 | 在架 |
| T008 | 头戴手电 | 在架，已归还 |
| T009 | 折叠推车 | 借出中的逾期 |
| T010 | 平板推车 | 借出中的未到期 |

总数是10件，在架4件、借出6件；借出的6件内部，再分为逾期2件、今日到期1件、未到期3件。检查两条等式：**4＋6＝10；2＋1＋3＝6**。不要把10、6和2等不同层级的数字相加，也不要把“借出6件”写成“有6个借用人”。一件工具是一行，不代表一个人只借了一件。

```text
请按已确认的规则逐件分类，新增“借还状态”“借出细分类”“分类依据”三列，但保留原始五列不变。
先给逐件明细，再给总数、在架数、借出数，以及借出内部的逾期/今日到期/未到期件数和对应编号。
做两次合计校验：在架+借出=总数；三个借出细分类合计=借出数。
完成后再制作简单状态图，注明模拟时点和单位“件”，不要从数据推断借用人的身份或责任。
```

### 第三步，把数字写成别人能读懂的说明

下面是本书编写的合格输出片段，可作为核对参考，不是某个千问办公账号的运行截图或成绩：

> 按2026年11月1日这一模拟核对时点，台账共10件工具，在架4件、借出6件。借出工具中，2件已逾期，1件今日到期，3件尚未到期。下一班可先复核T001、T009两条逾期记录，再核对T002的归还情况。台账未包含工具完好情况和联系人，应另行向负责人确认。

给值班人员的说明应保留时点、单位、分组关系和待确认事项。不要写“逾期工具造成损失”“某位居民屡次违约”，因为材料没有这些证据。需要提醒借用人时，另由有权限的负责人确认对象、内容和发送方式；本题不需要发送消息。

### 第四步，生成文件并完成交接

数字确认后，再要求生成`.xlsx`文件，分开保存原始记录、分类明细和汇总。若要给不会操作表格的人阅读，可另交一份简明PDF或文字说明。文件生成后自己打开，确认数字没有变成不可核对的装饰图，也没有漏掉T003、T007两行。

交接清单可以这样写：原始CSV保持不变；汇总采用2026-11-01时点；两条合计已核对；T001、T009待负责人复核；工具完好情况和联系人未提供；下一次更新前需核实新增借还记录。把文件名、用途和状态一起写下，比只发一个“最新版”文件更清楚。

千问办公官方说明支持在任务中加入文件、分析数据并生成多类交付物；实际可用格式和入口以当前账号与工作台为准。[文件任务流程](https://docs.qwenwork.cn/getting-started/basic-workflow) · [数据分析示例](https://learn.qwenwork.cn/docs/tasks/data-analysis.html)

### 交出去之前，做五个小检查

核对十个编号一个不少；确认统计时点写成11月1日；确认两条等式成立；抽查一件逾期、一件今日到期和一件已归还；最后打开文件检查文字、表格和图表。五项都通过，才把结果标为可供负责人审阅。

想继续练习，可以只改变一个条件：把核对时点改为11月2日，其余材料不变。此时T002从今日到期变为逾期，T010变为今日到期；在架仍是4件、借出仍是6件。先自己判断，再让AI重算。这能检查它是否真的采用你给的口径，而不只是重复上一轮的答案。
